# DXD Website

Public-facing site for the Digital Excellence & Products Division (DXD), MOE:
purpose/mission, products, people, perspectives, and careers.

Plain HTML/CSS/JS, no build step, no npm dependency — open `index.html`
directly or serve the folder with any static file server, e.g.:

    python3 -m http.server 8000

Design language: see `DESIGN.md`. Content in `products.html`, `people.html`,
`perspectives.html`, and `careers.html` is placeholder — replace with real
entries when ready. Products are grouped under five mission spaces (Students,
Schools & Teachers, Parents, HQ, Platforms & Infrastructure); each currently
shows three sample products per space, not the full catalogue.
