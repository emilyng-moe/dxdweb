# DXD Website

Public-facing site for the Digital Excellence & Products Division (DXD), MOE:
about/mission, products, people, and stories.

Plain HTML/CSS/JS, no build step, no npm dependency — open `index.html`
directly or serve the folder with any static file server, e.g.:

    python3 -m http.server 8000

Design language: see `DESIGN.md`. Content in `products.html`, `people.html`,
and `stories.html` is placeholder — replace with real entries when ready.
